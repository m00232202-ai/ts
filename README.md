# T-STRIKE — сборка в .exe (Electron)

Игра обёрнута в [Electron](https://www.electronjs.org/): это Chromium + Node.js
в одном exe-файле. Сама игра (`game/index.html`) не переписана — она грузится
как есть, через локальный сервер на `127.0.0.1`, который поднимает `main.js`.

## Структура

```
t-strike-exe/
├── game/
│   └── index.html      ← твоя игра (без изменений)
├── main.js              ← окно Electron + локальный сервер
├── package.json          ← зависимости и настройки сборки
├── .github/workflows/build.yml  ← автосборка на GitHub
└── build/                ← сюда можно положить icon.ico (необязательно)
```

## Вариант A: сборка через GitHub (как ты и хотел)

1. Создай новый **пустой** репозиторий на GitHub.
2. Залей туда всю папку `t-strike-exe` (через `git push` или веб-интерфейс
   GitHub — «Add file → Upload files», перетащи всё содержимое папки,
   сохраняя структуру `.github/workflows/build.yml`).
3. Открой вкладку **Actions** в репозитории — сборка запустится сама
   (файл `build.yml` уже настроен на автозапуск при пуше).
4. Через 2–4 минуты в этом же прогоне (Actions → последний run → Artifacts)
   появится **T-STRIKE-Windows-build** — там `.exe`-инсталлятор и
   портативная версия. Скачай архив, внутри будут готовые exe.

Ничего вручную собирать не нужно — GitHub сам всё соберёт на своём Windows-сервере.

## Вариант B: сборка локально (если у тебя есть Node.js на Windows)

```bash
npm install
npm run build
```

Готовые файлы появятся в папке `dist/`.

Проверить, что игра вообще открывается в Electron, можно командой:
```bash
npm install
npm start
```

## Важно понимать про 3D

Игра **уже полноценно 3D** — она сделана на Three.js/WebGL, это работало
и в браузере. Exe-обёртка (Electron) сама по себе 3D не «включает» и не
улучшает графику. Она даёт другое:

- Игра открывается как отдельное приложение, без адресной строки и вкладок браузера.
- Можно раздавать `.exe` людям, которым не нужно ничего вручную запускать.
- При желании через Node.js (`main.js`) можно дать игре доступ к файловой
  системе — например, чтобы загружать свои `.glb`/`.obj` 3D-модели с диска
  без ограничений браузера (CORS). Сейчас это не подключено, но добавить
  несложно, если понадобится.

Мультиплеер (Firebase / PeerJS / WebRTC) как использовал интернет, так и
использует — exe без сети работать в мультиплеере не будет, это не связано
с самим Electron.

## Иконка (необязательно)

Если хочешь свою иконку — положи файл `build/icon.ico` (256×256,
формат `.ico`) в проект перед сборкой, `main.js` подхватит его сам.
